# Руководство по тестированию функций аутентификации

## Запуск проекта

1. Откройте проект в VS Code
2. Правой кнопкой на `index.html` → **Open with Live Server**
3. Откройте консоль браузера (F12 → Console)

## Сценарии тестирования

### 1. Регистрация нового пользователя

**Успешный сценарий:**
1. Перейдите на страницу Register
2. Заполните все обязательные поля:
   - First Name: `John`
   - Last Name: `Doe`
   - Email: `john@test.com`
   - Phone: `+77011234567` (опционально)
   - Password: `test123`
   - Confirm Password: `test123`
3. Нажмите Register
4. **Ожидаемый результат:** переход на главную страницу, в навбаре появились Profile и Logout

**Проверка валидации (каждый сценарий отдельно):**
- Пустая форма → "First name is required", "Last name is required" и т.д.
- Неверный email (например, `test@`) → "Please enter a valid email"
- Короткий пароль (`123`) → "Password must be at least 6 characters"
- Разные пароли → "Passwords do not match"
- Повторная регистрация того же email → "This email is already registered"
- Неверный формат телефона → "Please enter a valid phone number"

### 2. Вход в систему

**Успешный сценарий:**
1. Перейдите на страницу Login
2. Введите:
   - Email: `admin@drivego.com`
   - Password: `admin123`
3. Нажмите Login
4. **Ожидаемый результат:** переход на главную, в навбаре появился пункт Admin

**Проверка валидации:**
- Пустые поля → "Email is required", "Password is required"
- Несуществующий email → "User with this email does not exist"
- Неверный пароль → "Incorrect password"

### 3. Редирект вошедших пользователей

1. Войдите в систему под любым пользователем
2. Попробуйте открыть `/login.html` или `/register.html` напрямую
3. **Ожидаемый результат:** автоматический редирект на главную страницу

### 4. Выход из системы

1. Войдите в систему
2. Нажмите Logout в навбаре
3. **Ожидаемый результат:** переход на страницу Login, навбар показывает пункт Login вместо Profile/Logout

### 5. Форма обратной связи (Contact)

**Успешный сценарий:**
1. Перейдите на страницу Contact
2. Заполните форму:
   - Your Name: `Test User`
   - Your Email: `test@example.com`
   - Message: `Test message`
3. Нажмите Send Message
4. **Ожидаемый результат:** зелёное сообщение "Thank you for your message!", форма очищена

**Проверка валидации:**
- Пустое имя → "Name is required"
- Пустой email → "Email is required"
- Неверный email → "Please enter a valid email"
- Пустое сообщение → "Message is required"

### 6. Навигация и адаптивность

**Десктоп (> 900px):**
- Все пункты меню видны горизонтально
- Admin виден только администратору

**Планшет/телефон (< 900px):**
- Появляется кнопка бургер-меню (☰)
- Клик открывает вертикальное меню
- Формы адаптируются к ширине экрана

**Активная страница:**
- Текущая страница подсвечена в навбаре (белый текст + синяя линия снизу)
